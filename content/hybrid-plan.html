🟢 Behavioral Core (Rust/WASM)

Same logical behavior, but uses native bitwise operations. The UI still shows gates visually.

// Behavioral ALU — one function, zero allocations
pub fn alu_execute(
  a: u8, b: u8, op: AluOp, carry: bool
) -> AluResult {
  match op {
    AluOp::Add => {
      let sum = a as u16 + b as u16 + carry as u16;
      AluResult { value: sum as u8, carry: sum > 0xFF }
    }
    AluOp::And => AluResult { value: a & b, .. },
    AluOp::Or  => AluResult { value: a | b, .. },
    AluOp::Xor => AluResult { value: a ^ b, .. },
    AluOp::Not => AluResult { value: !a, .. },
    AluOp::Shl => AluResult { value: a << 1, .. },
    AluOp::Shr => AluResult { value: a >> 1, .. },
  }
}
// RAM — just a byte array, O(1) access
pub struct Ram {
  data: [u8; 256],  // 256 bytes, that's it
  mar: u8,
}
impl Ram {
  pub fn read(&self) -> u8 {
    self.data[self.mar as usize]
  }
  pub fn write(&mut self, val: u8) {
    self.data[self.mar as usize] = val;
  }
}

Key insight: The Rust core computes everything at max speed. After each step (or batch of steps), it exposes a snapshot of all internal signals — which registers are enabled, what the ALU is doing, bus values, control signals. The React frontend reads this snapshot and renders a beautiful gate-level visualization that looks like the simulation is running gate-by-gate, even though the core is behavioral.
🎯 The "Best of Both Worlds" Trick

How the Visual Gate Layer Works

When you step one instruction, the Rust core emits a signal trace — a record of every control signal, bus value, and register change that happened during that cycle. The React frontend animates this trace as if gates are firing one by one:

🔬 Single-Step Mode

Step through one instruction at a time. See every micro-operation: fetch → decode → execute. The UI animates data flowing through gates, buses lighting up, registers loading. Slow enough to learn, rich enough to understand.

Educational ~60fps animation

🚀 Run Mode

Execute thousands or millions of cycles per frame. The UI shows a live dashboard: register values updating, memory heatmap, instruction counter climbing, output display showing results. Fast enough to run real programs.

Performance ~50M cycles/sec

🗺️ Implementation Roadmap

Phase 1: Rust Core — CPU + ALU + RAM Week 1-2

Port your computer's logic to behavioral Rust. Define CPU struct with R0-R3, ACC, IAR, IR, TMP, flags. Implement ALU with all 8 operations. RAM as [u8; 256]. Write comprehensive tests (you already have tests — great!). Compile to WASM with wasm-pack.

Phase 2: Control Section + Instruction Set Week 2-3

Implement the control section as a microcode state machine (your Stepper7 becomes a simple counter). Define the instruction set: LOAD, STORE, ADD, SUB, JMP, etc. Build the fetch-decode-execute cycle. Add signal trace recording for every micro-operation.

Phase 3: React Dashboard Week 3-4

Build the visualization layer: register panel, memory hex view, control signal display, toolbar with step/run/pause. Wire up to WASM bridge. Get single-stepping working with live state updates. Dark theme (obviously).

Phase 4: Assembly Editor + Gate Animations Week 4-6

Add the assembly language editor with syntax highlighting and error markers. Build the animated SVG gate diagrams that light up based on signal traces. Implement the oscilloscope-style signal trace viewer. Add breakpoints.

Phase 5: Polish + Electron Wrapper Week 6-8

Optional Electron wrapper for desktop app (you know this well!). Save/load programs. Example programs (fibonacci, sort, etc). Performance profiling and optimization. Documentation.
